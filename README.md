# Reality Wake

A disposable movement toy for **Dimensional Awakening**. Your path injects energy into a living terrain simulation; chemistry spreads it, waves keep it moving, and memory preserves the damage.

## Play

- Desktop: WASD or arrow keys. Hold Shift to surge. Drag to orbit the camera.
- Phone: left thumbstick to move; drag the right side to orbit.
- Sound is optional and reacts to velocity, disturbed terrain, intersections, and closed wakes.

Try crossing your own wake, closing a loop, or repeatedly circling one of the standing forms.

## Local

```bash
npm install
npm run dev
```
